# 投融资股权架构智能体

> **一句话口令驱动的企业投融资架构设计与审核系统**  
> 输入：`生成架构` 或 `审核架构` → 自动执行全流程分析与方案输出

## 功能概述

### 核心能力
1. **架构生成**：根据导入的企业资料、融资需求、上市规划等，自动生成最优股权架构方案
2. **架构审核**：对现有股权架构进行全面分析，识别风险点并提出优化建议
3. **知识库驱动**：整合法规、案例、理论，提供专业级方案输出

### 支持场景
- 创业公司股权分配设计
- Pre-IPO 股权架构搭建
- 红筹/VIE 架构设计与拆除
- 多轮融资稀释测算
- 员工股权激励方案
- 对赌协议条款设计
- 跨境投融资架构

## 快速开始

### 环境要求
- Python 3.12+
- Flask 5.x
- SQLite 3

### 安装部署
```bash
# 1. 克隆项目
cd D:\投融资股权架构智能体

# 2. 安装依赖
pip install -r requirements.txt

# 3. 初始化数据库
python scripts/init_db.py

# 4. 启动服务
python app.py
```

服务启动后访问：http://localhost:5299

```
生成架构
```

## 核心功能模块

### 1. 架构分析引擎（analyzer.py）
```python
class ArchitectureAnalyzer:
    def analyze(self, materials):
        """
        全面分析现有架构
        - 控制权路径清晰度
        - 融资能力评估
        - 上市合规性
        - 税负水平
        - 退出机制完整性
        """
```

**分析维度**：
- 控制权稳定性（67%/51%/34%关键生命线）
- 股权集中度与分散度平衡
- 融资空间（预留比例、稀释路径）
- 激励池设置合理性（10-20%）
- 对赌条款风险（与公司/股东对赌）
- 37号文/ODI合规性
- 税务筹划优化空间

### 2. 架构生成引擎（generator.py）
```python
class ArchitectureGenerator:
    def generate(self, requirements):
        """
        根据需求生成最优架构
        - 匹配行业特征
        - 融资阶段适配
        - 上市地选择
        - 控制权保护
        - 税务筹划
        """
```

**生成流程**：
1. 需求解析（融资额/估值/上市地/控制权要求）
2. 模板匹配（从知识库选择最佳基础模板）
3. 参数调优（股权比例、层级数量、持股主体）
4. 风险评估（合规性、税负、流动性）
5. 方案输出（架构图+协议清单+实施路径）

### 3. 风险扫描器（risk_scanner.py）
```python
class RiskScanner:
    def scan(self, architecture):
        """
        扫描22类常见风险
        - P0：阻断性风险（影响融资/上市）
        - P1：重大风险（需尽快修复）
        - P2：优化建议（提升架构质量）
        """
```

**风险清单**：
| 风险类别 | 检测项 | 等级 |
|---------|--------|------|
| 控制权 | 创始人持股<34%且无AB股 | P0 |
| 外资准入 | VIE用于非限制行业 | P0 |
| 对赌协议 | 与目标公司对赌未减资 | P1 |
| 员工激励 | 激励池<5%且无预留 | P1 |
| 代持清理 | 存在代持未清理 | P0 |
| 37号文 | 境外持股未登记 | P0 |
| 税务筹划 | 持股平台注册地无优惠 | P2 |

### 4. 优化建议引擎（optimizer.py）
```python
class ArchitectureOptimizer:
    def optimize(self, analysis_result):
        """
        基于分析结果给出优化方案
        - 控制权加固方案
        - 融资空间拓展
        - 税负降低路径
        - 合规整改清单
        """
```

**优化策略库**：
- 控制权不足：一致行动人协议 / AB股设计 / 委托投票权
- 融资空间受限：老股转让 / 可转债 / 期权池预留
- 税负过高：迁址税收洼地 / 合伙企业穿透 / 递延纳税备案
- VIE合规：协议更新 / 数据安全评估 / 备案补充材料
- 红筹拆除：减资方案 / 股权回购 / 境内重组

## 典型工作流

### 场景一：创业公司首次融资架构设计

**输入材料**：
- 公司信息：注册资本500万，3位创始人（55%/30%/15%）
- 融资需求：A轮3000万，估值2亿，释放15%股权
- 未来规划：3年内科创板上市

**口令**：`生成架构`

**系统输出**：
1. **股权架构方案**
   - 创始人通过有限合伙持股平台持股（控制权稳定）
   - 预留15%期权池（通过员工持股平台代持）
   - A轮投资人直接持股15%
   - 创始人持股路径：创始人→持股平台（GP）→目标公司

2. **控制权保护**
   - 创始人担任持股平台GP，享有100%表决权
   - 章程约定重大事项需创始人67%以上同意
   - 一致行动人协议（3位创始人）

3. **融资条款建议**
   - 对赌主体：创始人（非目标公司）
   - 业绩承诺：3年净利润不低于5000万
   - 反稀释条款：加权平均法
   - 回购条款：IPO失败时创始人回购

4. **税务筹划**
   - 持股平台注册地：宁波/霍尔果斯（税收洼地）
   - 递延纳税备案：激励对象适用101号文
   - 分红路径：公司→持股平台（免税）→个人（20%）

5. **实施路径**（7步）
   1. 设立2个有限合伙企业（创始人平台 + 员工平台）
   2. 创始人将股权转入持股平台（平价转让）
   3. 办理工商变更（目标公司股东变更为持股平台）
   4. 员工持股平台预留期权池（代持15%）
   5. 投资人与创始人签署对赌协议
   6. 投资人直接增资目标公司
   7. 修改公司章程（控制权保护条款）

6. **输出文件**（6个）
   - 股权架构图（多层级可视化）
   - 持股平台合伙协议（2份）
   - 股东协议（含对赌条款）
   - 公司章程修正案
   - 员工股权激励方案
   - 实施时间表（甘特图）

### 场景二：Pre-IPO公司架构审核

**输入材料**：
- 现有架构图（PDF）
- 3轮融资协议（含对赌条款）
- 员工股权激励方案
- 公司章程

**口令**：`审核架构`

**系统输出**：

**审核报告（8大维度）**

#### 1. 控制权分析 ✅
- 创始人合计持股：42%（通过持股平台）
- 一致行动人协议：有效
- 重大事项表决：需67%（有效保护）
- **结论**：控制权稳定

#### 2. 融资历史合规性 ⚠️
**P0问题**（1项）：
- A轮对赌协议约定目标公司回购，未履行减资程序
- **风险**：投资人诉讼风险，影响上市
- **整改方案**：
  1. 与投资人协商修改对赌主体为创始人
  2. 或目标公司立即履行减资程序（需股东会67%同意）

**P1问题**（2项）：
- B轮未办理递延纳税备案（员工激励部分）
  - **影响**：员工行权时税负增加（45% vs 20%）
  - **整改**：补办101号文备案（窗口期6个月）
  
- 境外投资人未完成ODI备案
  - **影响**：资金回流受限
  - **整改**：补办商务部ODI备案

#### 3. 员工激励方案 ⚠️
- 期权池：10%（偏低，建议15-20%）
- 持股平台：有限合伙（合规）
- 行权价格：公允价30%折扣（合理）

**P2建议**：
- 增加期权池至15%（老股东同比例稀释）
- 完善退出机制（离职回购条款）

#### 4. 红筹架构（如适用）❌
- 未搭建红筹架构
- 如计划港股上市，建议评估是否需要搭建

#### 5. 税务筹划 ⚠️
- 持股平台注册地：北京（无税收优惠）
- **优化建议**：迁址至宁波（地方留存40%返还）
- **测算**：上市后减持1亿，节税800万

#### 6. 对赌条款风险 🔴
**高危条款**（B轮协议第8条）：
```
"若公司2026年净利润低于5000万，投资人有权要求公司以2倍投资款回购股权"
```
- **问题**：与目标公司对赌 + 保底收益
- **法律风险**：违反《九民纪要》，可能被判无效
- **整改方案**：
  1. 修改回购主体为创始人
  2. 删除固定收益条款
  3. 与投资人重新签署补充协议

#### 7. 关联交易清理 ✅
- 无关联交易
- 资金往来清晰

#### 8. 上市合规性（科创板） ⚠️
**待整改清单**（5项）：
1. 代持清理（2名员工代持未显名）
2. 社保公积金补缴（3个月）
3. 实际控制人认定文件（需律所出具）
4. 对赌协议修改（见上）
5. 递延纳税备案补办（见上）

**预计整改周期**：6个月

---

**综合评分**：72/100（中等偏上，需整改）

**核心建议**（3条）：
1. **P0优先**：立即修改B轮对赌协议，避免诉讼风险
2. **税务优化**：持股平台迁址，节税空间800万+
3. **上市加速**：6个月完成清单，2026 Q4申报

---

**输出文件**（4个）：
- 架构审核报告（PDF，28页）
- 风险清单（Excel，22项）
- 整改路径（甘特图）
- 优化方案对比表（3套方案）
